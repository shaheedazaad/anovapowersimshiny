Superpower examples recreated with anovapowersim

pkg <- "/Users/shaheedazaad/Projects/afexpower"

devtools::load_all(pkg, quiet = TRUE)

alpha_level <- 0.05
n_sims <- 5000

run_power_curve <- function(n, ..., sims = n_sims, seed = 20260509) {
  power_curve(
    ...,
    n_range = n,
    n_sims = sims,
    alpha = alpha_level,
    progress = FALSE,
    parallel = TRUE,
    seed = seed
  )
}

This document recreates the Superpower validation examples that map directly onto power_curve(): balanced ANOVA-level effects with a common standard deviation and, for repeated-measures cells, a single compound-symmetric correlation. Examples that require custom covariance matrices, unequal standard deviations or sample sizes, MANOVA, emmeans/pairwise tests, assumption violations, mixed models, or non-ANOVA outcomes are outside the current power_curve() and power_n() interfaces.

For each example, I use the partial eta squared reported by Superpower’s exact calculation as target_pes. Because these are fixed-N validation cases, each chunk calls power_curve() with a single n_range value through the helper run_power_curve(). The helper uses n_sims = 10000 by default; the very large n = 5000 effect-size checks use fewer simulations because the analytic power_calc is already 1.00 and full simulation would make rendering unnecessarily expensive.
